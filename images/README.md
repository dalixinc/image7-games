# Images

Artwork for Image 7 Synthetics documents, release notes and web pages.

## logos/

Erin Art(TM). The approved Image 7 Synthetics brand marks.

| File | Use it for |
|---|---|
| `image7-synthetics-logo-full.png` | The original approved full logo (1774 x 887, cream background) |
| `image7-synthetics-logo-1200w.png` | Documents and slides |
| `image7-synthetics-logo-800w.png` | Compact layouts |
| `i7-icon-transparent-*.png` | The I7 icon on any background (512, 128, 64, 32 pixels) |
| `i7-icon-dark-*.png` / `i7-icon-light-*.png` | The I7 icon on a dark or light background |
| `i7-icon-*.ico` | Favicons and app icons |

The full logo is a raster image, not an editable vector.
